# Appy.Spatial.GeoJSON

## What is Appy.Spatial.GeoJSON?

AppyWay geojson model and json serialization converters.

## Supported frameworks

The packages target `net10.0` and `net8.0`; apps on `net9.0` use the `net8.0` build.
Version 2.0 dropped `netstandard2.0` and `net6.0`: .NET Framework and older .NET apps should stay
on 1.4.x.
